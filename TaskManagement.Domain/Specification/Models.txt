لایه Domain
===========
دو مدل اصلی وجود دارد: User و TaskItem.
خود مدل‌ها منطق ذخیره‌سازی ندارند. عملیات اجرایی روی آن‌ها از طریق اینترفیس‌های همین لایه تعریف شده است.


۱) مدل User
-----------
جدول: Users

خصوصیت‌ها:
- Id            عدد صحیح، کلید اصلی
- FirstName     نام، اجباری، حداکثر ۷۵ کاراکتر
- LastName      نام خانوادگی، اجباری، حداکثر ۷۵ کاراکتر
- Email         ایمیل، اجباری، حداکثر ۲۵۶ کاراکتر، یکتا
- PasswordHash  هش رمز عبور، اجباری 
- DisplayName   فقط خواندنی: FirstName + فاصله + LastName
           

رابطه‌ها:
- CreatedTasks   تسک‌هایی که این کاربر ساخته است
- AssignedTasks  تسک‌هایی که به این کاربر اختصاص داده شده است

متد اجرایی روی User (IUserRepository):
- GetAllAsync()
  همه کاربران را برمی‌گرداند. مرتب‌سازی: نام، بعد نام خانوادگی.

- GetByIdAsync(id)
  یک کاربر را با شناسه پیدا می‌کند. اگر نباشد null.

- GetByEmailAsync(email)
  یک کاربر را با ایمیل پیدا می‌کند. برای ورود و جلوگیری از ایمیل تکراری در ثبت‌نام.

- AddAsync(user)
  کاربر جدید را برای ذخیره علامت می‌زند.

- SaveChangesAsync()
  تغییرات را در دیتابیس ثبت می‌کند.


۲) مدل TaskItem
---------------
جدول: Tasks

خصوصیت‌ها:
- Id            عدد صحیح، کلید اصلی
- Title         عنوان، اجباری، حداکثر ۲۰۰ کاراکتر
- Description   توضیحات، اجباری
- CreatedAt     تاریخ ایجاد
- CreatorId     شناسه سازنده (FK به Users.Id)
- Creator       کاربر سازنده
- AssignedToId  شناسه کاربر اختصاص‌داده‌شده (FK به Users.Id)
- AssignedTo    کاربر مسئول تسک
- IsDeleted     حذف نرم؛ true یعنی حذف شده ولی ردیف می‌ماند
- DeletedAt     زمان حذف نرم

رابطه‌ها:
- هر تسک یک سازنده دارد (Creator)
- هر تسک به یک کاربر اختصاص دارد (AssignedTo)
- حذف کاربر اگر تسک داشته باشد مجاز نیست (Restrict)

متد اجرایی روی TaskItem (ITaskRepository):
- GetByIdAsync(id)
  یک تسک را با سازنده و کاربر اختصاص‌داده‌شده برمی‌گرداند.

- GetCreatedByUserAsync(userId)
  تسک‌هایی که این کاربر ساخته است، جدیدترین اول.
  تسک حذف‌شده هم در لیست می‌ماند.

- AddAsync(task)
  تسک جدید را برای ذخیره علامت می‌زند.

- Update(task)
  ویرایش یا حذف نرم را برای ذخیره علامت می‌زند.

- SaveChangesAsync()
  تغییرات را در دیتابیس ثبت می‌کند.
